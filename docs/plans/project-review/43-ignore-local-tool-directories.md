# 43. 로컬 도구 디렉터리를 Git 제외 규칙에 추가

기준 `cd65525` · 우선순위 낮음 · 리뷰 ⑭ · 반영 완료

## 수정 범위

루트와 계획서 폴더의 `.omc/`가 반복해서 미추적 파일로 표시된다. 실수로 커밋하는 일을 줄이기 위해 루트 `.gitignore`에 이름이 정확히 `.omc`인 디렉터리에 적용되는 규칙 `.omc/` 한 줄을 추가한다. 파일을 옮기거나 삭제할 필요는 없다. [현재 제외 규칙](../../../.gitignore)

## 완료 기준과 최소 검증

`git check-ignore -v -- .omc/ docs/plans/project-review/.omc/`로 두 위치에 의도한 규칙이 적용되는지 확인한다. diff는 제외 규칙에만 있어야 한다. 리뷰가 예시로 든 헤더와 설정 파일은 Git 인덱스에서 이미 LF이므로 줄바꿈 일괄 정리는 작업 범위 밖이다.

## 반영 결과

루트 `.gitignore`에 `.omc/`를 추가했다. `git check-ignore -v`에서 루트와 `docs/plans/project-review/` 아래의 `.omc/`가 모두 이 규칙에 일치했다.
