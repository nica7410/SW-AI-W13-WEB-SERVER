## 구현 순서

1. README에 기존 표의 기준 커밋을 눈에 띄게 표시하고 수치와 조건을 보존한다. 제목을 바꿀 경우 기존 계획 문서에서 참조하는 측정 섹션 링크도 유지한다.
2. 새 커밋의 두 행을 별도 표로 추가한다. 출처는 사용자가 제공한 외부 리뷰 요약으로 명시한다. `non_2xx=0`은 응답 상태 집계다. 연결·읽기 실패와 응답 길이 오류는 `failed`로 별도 집계된다.
3. 비교 문구는 “보고된 keep-alive 두 조건에서 처리량이 이전 표보다 높게 관찰됐다”까지로 제한한다. 전체 성능이나 지연에 대한 개선율을 산출하려면 동일 조건의 원자료가 필요하다.
