# 48. 부하 측정 도구별 적용 옵션 명시

기준 `dev@37a55e8` · 후속 작업 2 · 리뷰 6-2 · 반영 완료

## 작업 범위

README는 `REQUESTS`와 `KEEPALIVE`를 공통 옵션처럼 소개한다. 스크립트는 설치된 도구에 따라 하나를 선택하며, 두 분기가 제어하는 측정 조건이 다르다. 사용자가 실행 전 어떤 조건이 적용될지 판단할 수 있게 README의 부하 측정 안내를 고친다. [스크립트](../../../tests/load.sh) · [README 검증 절](../../../README.md#검증)

## 반영할 내용

- 선택 순서는 `ab` 우선, 없으면 `wrk`다. `URL`과 `CONCURRENCY`는 두 분기에 모두 적용된다.
- `ab`는 `REQUESTS`로 총 요청 수를 정하고 `KEEPALIVE=1`이면 `-k`를 추가한다. `wrk`는 `DURATION`으로 실행 시간을 정하며 기본값은 3초다. 현재 `wrk` 명령에는 `REQUESTS`·`KEEPALIVE`를 전달하는 옵션이 없다.
- 두 도구의 예시는 실제 분기에 맞춰 표시한다. 결과를 인용할 때 해당 도구와 요청 수 또는 실행 시간, 동시 연결 수, 연결 재사용 조건을 함께 읽을 수 있게 한다.

## 완료 기준과 최소 검증

README의 옵션과 예시를 `tests/load.sh`의 분기·기본값·실제 인자와 대조하고 문서 diff를 확인한다. 기록된 과거 측정값은 그대로 인용한다. 이 작업은 벤치마크 실행이나 스크립트 변경 없이 완료할 수 있다.

## 반영 결과

README에 도구 선택 순서, 공통 입력, 도구별 요청 수·연결 재사용·실행 시간 옵션과 예시를 기록했다. `tests/load.sh`의 두 실행 분기와 기본값을 문서 diff와 대조했다.
